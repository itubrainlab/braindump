**brAIn dump is now brAIn stream.** This release also brings an automated
validation procedure for the lab's two-computer setup, and fixes LSL markers
being recorded twice.

## The new name

brAIn dump is renamed **brAIn stream** ([#8](https://github.com/itubrainlab/brainstream/issues/8)):

- the app, the packages (`brAInstream-<version>-…`) and the command
  (`brainstream`);
- the repository: [itubrainlab/brainstream](https://github.com/itubrainlab/brainstream).
  The old address redirects to it.

**Upgrading from brAIn dump.** Install brAIn stream as usual.

- **Settings and recent projects** move over the first time it starts.
- **`.braindump` projects** open and save as they are. New projects are
  `.brainstream`, in `~/brAIn stream` by default.
- **The old app** stays installed until you remove it: delete *brAIn dump*
  from Applications (macOS), or run its uninstaller (Windows, Linux).
- **On macOS**, allow camera access once more for the new app.

## Markers recorded once

**The bug.** A procedure started, aborted and started again had every LSL
marker recorded twice. Its new marker stream had the same name and
`source_id` as the old one, so LSL re-attached the old run's connection to it
while brAIn stream opened a second.

**The fix.** Each connection now stays with the stream it opened, and every
marker is recorded once.

**Recordings already made.** Those with doubled markers are flagged by the
validation analysis, which counts each marker once.

## Validating the lab's setup

[validation/LAB.md](https://github.com/itubrainlab/brainstream/blob/v0.5.0/validation/LAB.md)
covers setting up the lab's booth, running a session and reading the report.
The booth has two computers:

| Computer | Devices |
|---|---|
| Recording | a 64-channel g.HIamp (channel 64 a bipolar horizontal EOG, 0.01–100 Hz and 50 Hz amplifier filters); a camera on the participant |
| Stimulus | the GP3 HD under `opengp3 server`; OBS over NDI; PsychoPy |

**The procedure.** PsychoPy runs the whole of it, including the eye
tracker's calibration:

1. flashes;
2. eyes open, then closed (alpha band power);
3. the calibration;
4. moving targets;
5. 30 faces at fixation crosses (N170);
6. moving targets and flashes again.

**Five checks.** The analysis passes or fails:

1. alpha;
2. EEG signal quality, now pass/fail;
3. gaze accuracy;
4. the N170;
5. synchronisation.

**Synchronisation** now compares every input:

| Pair | How |
|---|---|
| EEG ↔ eye tracker | the EOG against the gaze, with no markers involved |
| Eye tracker ↔ markers | the moving targets; saccades to the crosses |
| Camera ↔ eye tracker | the eyes' jumps, found in the camera's video, against the gaze |
| OBS ↔ markers | the faces and the flashes |
| Markers | each recorded once |

When OBS or the camera is steadily late, the report gives the Delay to set.

**The project in one command.** `make_project.py --lab` makes it. The
g.HIamp's filters are chosen by their cut-offs from those the amplifier
offers.

**g.HIamp: Other channels.** A new setting types channels that aren't EEG
(e.g. `64=EOG`), and the recording's `channels.tsv` and `eeg.json` say so.

## Changes

- Release builds run the tests in 4 workers, and build the packages while
  the tests run: about 3½ minutes from tag to release, from 8.
- The logo is shown at the top of the README.

## Install

The Windows zip, the macOS DMG (Apple Silicon, macOS 14+) or the Linux tarball
(x86_64, glibc 2.34+). The first launch downloads g.Pype 4.2, g.tec's drivers
(gtec-unicorn, gtec-gds), OpenGP3, MediaPipe, NDI and the other libraries
from PyPI.
