brAIn dump now records through one g.Pype 4.2 pipeline, and the EEG
amplifiers' filters can be set for the recording.

## One g.Pype pipeline

Every connected device is a source in a single
[g.Pype](https://gpype.gtec.at) 4.2 pipeline, and every BIDS file is written
by a g.Pype sink.

- **Amplifiers.** The Unicorn and the g.HIamp run on g.Pype's own amplifier
  sources. brAIn dump keeps each scan's measured acquisition time on top of
  them, as before, and gives it back to g.Pype, so UDP triggers land on the
  EEG sample they belong to.
- **The other devices** (GP3, Polar, Shimmer, LSL markers, video) push their
  samples into the same pipeline.
- **Connecting or disconnecting** a device restarts the pipeline. It is not
  allowed while recording. If one device fails, every device stops, and the
  message names the one that failed.
- **Rhino Recorder is no longer needed.** The parts brAIn dump used (the
  simulated Unicorn, filter presets, the scope and spectrum views) now live
  in brAIn dump.

## EEG filters

- **Unicorn.** The filters applied to the recording are set in the device's
  settings, from every filter g.Pype offers: by default a 0.1 Hz high-pass and
  no low-pass. The Filter and Notch boxes above the scope only change what is
  shown. `channels.tsv` gives each channel's cut-offs and notch.
- **g.HIamp.** The amplifier's own band-pass and notch filters, chosen in its
  settings. **Load from amplifier** fills the lists with the filters the
  amplifier offers at the chosen sampling rate. They are recorded as the EEG's
  hardware filters.

## Changes

- The OBS device is now **Screen Capture**, and the webcam device is
  **Video Stream**.
- **Video Stream opens the camera you chose.** On macOS the wrong camera
  could open, because OpenCV numbers cameras in a different order from the
  list shown. The page now remembers the camera itself. If that camera is
  unplugged, the device refuses to connect rather than open another, and the
  list marks it "(not connected)".
- The Unicorn's Bluetooth delay defaults to g.tec's measured 40 ms, taken from
  g.Pype.

## On the lab's hardware

A MacBook's own screen, with a Unicorn, the GP3 under `opengp3 server`, LSL
markers from PsychoPy, OBS over NDI (39 ms delay set) and the MacBook's
camera, through the [validation procedure](https://github.com/itubrainlab/braindump/tree/main/validation):

| Check | Result |
|---|---|
| Alpha | **Passed**: 1.9× with the eyes closed |
| N170 | **Passed**: 180 ms, p < 0.001 |
| Synchronisation | **Passed**: the screen 3 ms after the markers, the same markers in `eeg/` and `beh/`, no camera frames dropped |
| Gaze | Median error 2.64°: the GP3 lost the eyes at the bottom of the laptop screen |

The Unicorn's timing matches 0.2.1's. A recording from a g.HIamp, a webcam and
OBS validated without errors.

## Install

The Windows zip, the macOS DMG (Apple Silicon, macOS 14+) or the Linux tarball
(x86_64, glibc 2.34+). The first launch downloads g.Pype 4.2, g.tec's drivers
(gtec-unicorn, gtec-gds), NDI and the other libraries from PyPI.
