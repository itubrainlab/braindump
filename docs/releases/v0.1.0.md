The first release of **brAIn dump**, the ITU brAIn lab's multi-device recorder:
record the lab's devices together into a BIDS dataset, on Windows, macOS and
Linux.

## Devices

- **g.tec Unicorn Hybrid Black**: 8-channel EEG at 250 Hz, through g.Pype, with
  Rhino Recorder's data viewer, signal quality and power spectrum. BDF with
  `_eeg.json` and `_channels.tsv`; triggers over UDP.
- **Gazepoint GP3**: eye tracking on this computer (OpenGP3's own driver) or on
  another one over the Open Gaze API (OpenGP3 server or Gazepoint Control).
  Eye view, calibration (5–25 points), validation, and a plot of the
  calibration's quality. BIDS eye-tracking physio for each eye, every channel,
  and fixations and blinks.
- **Polar H10**: ECG at 130 Hz, acceleration, heart rate and every RR interval,
  over Bluetooth LE.
- **Shimmer3 GSR+**: skin conductance and the ear clip's PPG, over Bluetooth.
- **LSL streams**: any Lab Streaming Layer stream (markers, typically),
  recorded as events.

Every device has a simulated version, for trying brAIn dump without hardware.

## Projects and recordings

- A project keeps its devices, their configuration and where its recordings
  go; brAIn dump opens on a project picker.
- Record asks for participant, session, task and run every time, and records
  every connected device together.
- Recordings pass the BIDS validator (1.10) without errors. All devices are
  time-stamped on the recording computer's clock; `scans.tsv` gives each
  file's start to the microsecond.

## Install

| System | Package | Install |
|---|---|---|
| Windows 10 or 11, 64-bit | `brAIndump-0.1.0-windows-x86_64.zip` | Unpack, double-click `install.cmd`; open brAIn dump from the Start menu. |
| macOS 14 or later, Apple Silicon | `brAIndump-0.1.0-macos-arm64.dmg` | Drag **brAIn dump** to Applications. The first time, right-click it and choose **Open** (the app is not notarized). |
| Linux x86_64, glibc 2.34+ | `brAIndump-0.1.0-linux-x86_64.tar.gz` | Unpack, run `./install.sh`; open brAIn dump from the applications menu or run `braindump`. |

**The first launch needs an internet connection**: it downloads g.Pype, g.tec's
Unicorn driver and the other libraries from PyPI (several hundred MB, a few
minutes), which g.tec's licence does not allow to be bundled. Later launches
start directly.
